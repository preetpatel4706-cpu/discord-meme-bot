# Discord Meme Bot 🤖

A Discord bot built with Python that responds to the `$meme` command by fetching and sending a random meme.

## Features

- Connects to Discord using `discord.py`
- Responds to the `$meme` command
- Fetches random memes using the Meme API
- Uses environment variables to keep the Discord bot token secure

## Technologies Used

- Python
- discord.py
- Requests
- python-dotenv
- Meme API
